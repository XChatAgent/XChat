# 客户端使用说明

## 登录

启动 XChat 后填写：

```text
服务器：管理员提供的地址，例如 host:51821
用户名：管理员分配的账号
密码：管理员分配的密码
```

点击“登录”。

登录成功后：

- 状态栏显示“认证成功”
- 自动获取 WireGuard 配置
- 自动启动隧道
- 日志区显示连接过程

> 首次连接会校验服务端 TLS 证书。如果服务端证书变更，客户端会拒绝连接，
> 需要管理员确认后用新安装包或新证书指纹更新。

## 连接与断开

主界面提供：

- 连接
- 断开
- 测试服务端

连接后状态区显示：

- 服务状态
- Endpoint
- 本机隧道地址
- 最近握手时间
- 收发流量
- DNS 状态

## 智能分流

智能分流会根据域名和国内 IP 段决定哪些流量走隧道、哪些直连。

适用场景：

- 国内网站直连，降低延迟
- 国外服务走隧道
- 减少全隧道对本地网络的影响

如果智能分流导致某些网站异常，可以先切换为全隧道模式排查。

## DNS 防泄漏

客户端会检查：

- 系统 DNS
- 隧道 DNS
- AllowedIPs
- IPv6 泄漏风险

发现异常时，状态区会显示警告。按提示开启 DNS 防泄漏或切换隧道模式。

## 日志

界面日志区会显示：

- TLS 连接结果
- 认证结果
- 配置获取
- 隧道启动
- DNS 分流
- 错误原因

日志文件：

```text
%LOCALAPPDATA%\XChat\XChat.log
```

反馈问题时可附上最近日志，但请先删除服务器地址、账号等敏感信息。

## 最小化与托盘

关闭窗口默认最小化到系统托盘，不中断连接。

退出程序请使用托盘菜单中的“退出”，不要直接结束进程。

## 自动更新

启动时会检查版本：

- 非强制更新：可在“帮助 → 检查更新”中手动触发
- 强制更新：启动后显示更新面板，下载并安装后重启

升级安装包会保留：

- 程序安装目录
- 用户数据
- 登录配置

## 文件接收

接收到的文件默认保存到：

```text
%LOCALAPPDATA%\XChat\received
```

可在设置中修改接收目录。
