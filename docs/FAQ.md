# 常见问题

## 安装时报错，提示服务启动失败

检查：

1. `C:\Program Files\XChat\ChatAgent` 是否存在
2. `XChatAgent.exe`、`Qt6Core.dll`、`Qt6Network.dll` 是否完整
3. Windows 服务中是否有 `XChatAgent`
4. 以管理员身份重新运行安装包

安装日志位于：

```text
%TEMP%\Setup Log YYYY-MM-DD #NNN.txt
```

## 安装程序没有让我选择目录

如果已经安装过同一版本，安装程序可能进入维护/升级模式。
仍然可以在选择目录页面修改目录；如果页面被跳过，请先卸载旧版本再安装。

## 登录失败

- 检查服务器地址和端口
- 检查用户名、密码
- 检查网络是否能访问服务器
- 检查系统时间是否准确（TLS 证书校验依赖时间）

## TLS 证书错误

客户端固定 TLS 证书指纹。证书变化后不会自动信任。

处理方式：

- 联系管理员确认证书是否已轮换
- 使用管理员提供的最新客户端或更新指纹文件

不要直接删除指纹文件来绕过校验。

## 连接成功但无法上网

按顺序检查：

1. 服务端 WireGuard 是否在线
2. Endpoint 是否可达
3. 是否开启了全隧道模式
4. 系统 DNS 是否正常
5. 尝试切换智能分流/全隧道
6. 查看日志中的隧道启动和 DNS 错误

## 关闭窗口后连接还在

这是正常行为。关闭窗口会最小化到托盘，不中断隧道。

需要退出时使用托盘菜单“退出”。

## 卸载后用户数据还在

用户数据保存在：

```text
%LOCALAPPDATA%\XChat
```

卸载程序不会删除该目录，避免误删聊天记录和配置。
需要彻底清理时手动删除。
